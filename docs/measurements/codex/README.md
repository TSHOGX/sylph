# codex measurements

Measured **2026-08-28** against **codex-cli 0.150.1** (`/opt/homebrew/bin/codex`),
store at `~/.codex/` holding 1258 `rollout-*.jsonl`.

Every claim in the codex section of `docs/agents.md` should be traceable to a file
here. `AGENTS.md` § "Reading a vendor payload" is the reason this directory
exists: the most-repeated defect class in this repo is reading the wrong key off
a vendor payload — eight instances, each one compiling — and the discipline that
catches it is printing one real payload instead of inferring field names.

## How to re-run

Every scenario needs a throwaway `CODEX_HOME` so the user's real store, journal,
and `notify` hook are never touched — the codex analogue of `AGENTS.md`'s rule
about never writing to a real `cc-socks` directory.

```sh
rm -rf /tmp/codex-probe-home && mkdir -p /tmp/codex-probe-home
cp ~/.codex/auth.json  /tmp/codex-probe-home/auth.json      # NOT committed
cp ~/.codex/config.toml /tmp/codex-probe-home/config.toml
python3 strip_notify.py /tmp/codex-probe-home/config.toml   # or it fires the user's hook

CODEX_HOME=/tmp/codex-probe-home python3 s02_turn.py
python3 redact_captures.py                                  # before committing anything
```

Scenarios spend **real tokens on a real account**. Prompts are deliberately
trivial ("reply with the word ok"); that is enough to see envelope shapes.

## `schema/`

Generated by the vendor itself, which makes it the best available evidence about
what the protocol *declares*:

```sh
codex app-server generate-json-schema --experimental --out schema
```

The 364 per-type `v2/` files and the two 700 KB bundled unions were deleted to
keep the tree small; `ClientRequest.json`, `ServerNotification.json`, and
`ServerRequest.json` carry every method name and every `ThreadItem` variant, so
regenerate if a per-type file is needed.

**A declared method is not a promise anything answers it, and a declared field
is not a promise it is populated.** Of 15 declared server-request kinds, real
turns produced exactly one (`item/commandExecution/requestApproval`); of 18
declared `ThreadItem` variants, six appeared. Grep the captures, not the schema,
before writing an adapter branch.

## Two transport traps worth reading before writing any client

**The unix listener speaks WebSocket; stdio speaks NDJSON.** Same JSON-RPC
vocabulary, different framing. An NDJSON frame on the socket gets the connection
closed with no data at all, and the server logs `failed to upgrade control
socket websocket connection: ... invalid token`. The upgrade is accepted on any
path (`/`, `/control`, `/rpc`, `/ws`, `/readyz`, `/healthz` all answer the same
`101`), so the path carries no meaning.

**codex's HTTP parser rejects a mainstream websocket client.** The `websockets`
package (16.0) fails its handshake with "did not receive a valid HTTP response"
because of the extra headers it sends; a hand-written upgrade carrying exactly
`Host`, `Connection`, `Upgrade`, `Sec-WebSocket-Version`, and
`Sec-WebSocket-Key` is answered `101`. That is why `miniws.py` exists, and it is
a real constraint on the envagent rather than a quirk of this probe.

Also: **the listen path's parent must be a real directory.** On macOS `/tmp` is
a symlink to `/private/tmp`, and codex refuses with `socket directory path
exists and is not a directory: /tmp`. A canonical path works; codex creates the
parent `0700` and the socket `0600`.

## `captures/`

Raw frames, one JSON object per line, with a direction marker and timestamp.
`s13_rollout_sample.jsonl` is a real rollout file rather than a wire capture.

**Run `redact_captures.py` before committing.** It removes, by key rather than
by regex over the blob: `installationId`, `serverName` (the machine's hostname —
Sylph's own invariant is that an environment id is never a hostname), any
token/pairing-code shaped key, and the third-party `base_url` this install is
configured against. It also elides `base_instructions`, which is the agent's
entire system prompt repeated per `session_meta`.

The daemon's own tracing output is stripped entirely rather than redacted:
key-based redaction cannot reach an identifier embedded in a free-text log line,
and the JSON-RPC frames are the evidence. That is also what took the corpus from
18 MB to 408 KB.

`auth.json` and `installation_id` from the real `~/.codex/` are **never** copied
into this tree.
